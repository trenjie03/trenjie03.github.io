# trenjie03.github.io

Personal portfolio. React + Vite, deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

## Editing content

All text lives in **`src/content.js`**: name, links, home intro, projects, and the about page. Images go in `public/` (e.g. `public/projects/logger.jpg` → `"/projects/logger.jpg"`).

Colours and fonts are the tokens at the top of `src/index.css`.

## Running locally

```bash
npm install
npm run dev
```
